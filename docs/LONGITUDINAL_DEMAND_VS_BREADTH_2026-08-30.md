# Longitudinal Demand vs Independent Breadth — 2026-08-30

## Trigger

Changed Method Navigator market research surfaced a useful demand pattern. In January 2026, one IntelliJ user described an Eclipse-style Git compare outline that lists changed methods and lets the reviewer focus method-by-method before committing. In late August 2026, the same Reddit account independently resurfaced in a Git Assistant release thread asking whether that plugin could show changes per method and focus the diff on one method. When told IntelliJ Structure/Local History could help, the user explicitly rejected those as non-equivalent and described a method-focused difference view as a major improvement.

This is stronger evidence than a one-off idea, but it is not multiple independent users.

## Core distinction

> **Repeated demand from one independent person strengthens persistence, not breadth.**

Do not count the same person appearing across multiple discussions or dates as multiple independent demand observations.

Represent demand as a vector rather than a scalar:

`D = breadth × persistence × intensity × recency × willingness_to_act × settlement_truth`

Where:

- **breadth** = number/diversity of genuinely independent users or buyers;
- **persistence** = whether the same need survives across time/context;
- **intensity** = strength/specificity of the expressed pain or desired resolution;
- **recency** = whether the need is still current;
- **willingness_to_act** = installs, trials, switching, payment or other costly choice;
- **settlement_truth** = actual paid/redeemable return when monetization is being evaluated.

## Anti-double-counting rule

Identity linkage across sources should reduce, not inflate, evidence count.

`same user + two dates = one breadth unit with higher persistence`

not:

`same user + two dates = two users`.

The same principle applies to wallets, organizations, bots, accounts, subsidiaries and platform-generated traffic.

## Changed Method Navigator implication

The repeated Reddit evidence materially raises confidence that the method-focused review problem is persistent and still unresolved in late August 2026. It does not establish a broad market or willingness to install/pay.

Therefore the plugin remains worthy of a narrow external probe, but Market Truth stays unresolved until genuinely independent user behavior returns.

## Compact form

`REPETITION ACROSS TIME != INDEPENDENCE ACROSS BUYERS`
