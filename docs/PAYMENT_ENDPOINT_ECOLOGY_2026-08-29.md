# Payment Endpoint Ecology — 2026-08-29

## Center correction

Do not start by inventing a business. Start from an already-funded economic endpoint, then grow backward toward a useful state transition and only then toward traffic.

`internet intent -> useful machine -> tracked state change -> funded endpoint -> payout`

A growing market is not automatically accessible demand. Committed demand is necessary but insufficient. Score the whole gradient:

`demand pressure - existing supply - competition - reproduction cost - human friction - infrastructure friction`

## Current nursery rules

1. Frequency must be earned by the rate of possible change.
2. Friction must earn troubleshooting.
3. No rabbit hole without evidence buying the next step.
4. Action attempted != action verified; require a confirmation artifact.
5. Prefer payment endpoints that allow zero-capital entry, objective conversions, low/no minimum payout, simple payout rails, and repeatable attribution.
6. Prefer one useful decision layer that can route to multiple legitimate endpoints over one site = one affiliate bet.
7. Existing Fruit/Soil should be reused before creating new code.

## Endpoint classes observed

### Direct recurring SaaS / utility affiliates

High accessibility examples found publicly on 2026-08-29:

- Document.com: 35% recurring for 180 days, 180-day cookie, PayPal or ACH, $0 payout minimum, no traffic/follower threshold, usually instant/24h approval.
- WebsitePolicies: 30% recurring, 90-day cookie, recurring payments credited indefinitely, PayPal/wire, no minimum payout, instant approval.
- Postcrest: 30% recurring for first year, 90-day cookie, PayPal, $0 minimum.
- Zyphra: 25% recurring for 12 months, 60-day cookie, PayPal/bank, $0 minimum, instant approval.
- LandingHero: 15% recurring lifetime, 60-day cookie, PayPal/bank, $0 minimum, instant approval.
- Subly: 30% recurring, 60-day cookie, monthly PayPal, no minimum.

These are platform claims, not evidence that Flower can convert traffic.

### Multi-offer performance networks

- CPAlead: live CPA/CPI marketplace, PayPal among payout methods, daily pay on many source-connected offers; however current publisher page says it is built for publishers who already have traffic and performance access may require earning thresholds. Penalize heavily for pre-traffic friction.
- MaxBounty: broad CPA demand and PayPal via payout platforms, but $100 minimum and application/manager friction. Not first-fruit optimal.
- AdWork Media: PayPal supported; $35 lead threshold; requires each website/media outlet approval. Not first-fruit optimal.

### Pay-per-call

BrokerCalls probe already sent to affiliate team. Treat as one rail, not the garden. Await verified reply; do not chase.

## Competitive pruning from this run

Generic legal-document selectors/generators are crowded (LegalTemplates, AI Lawyer, ContractPapers, LegalDraft AI, etc.). Do not build another generic document generator merely because Document.com has a favorable affiliate endpoint.

Generic privacy-policy generators/checkers are also crowded. WebsitePolicies remains a useful payment endpoint, but a new organism must add a narrower state transition rather than clone a policy generator.

## Reuse insight

Existing public Fruit includes `rag-crawl-preflight`. Before building a new AEO/AI-visibility utility, test whether this existing diagnostic can be connected to a recurring AI-visibility/SEO endpoint. Reusing working Fruit is cheaper than producing another utility from scratch.

## Next research pressure

Find state transitions where:

- the user arrives with an urgent yes/no/which-next decision;
- the answer can be produced objectively from public or user-supplied facts;
- an existing paid endpoint directly resolves the next step;
- competitors do not already collapse the same transition;
- a useful free machine can exist without paid APIs;
- payout can reach PayPal or another low-friction rail;
- one organism can route to multiple endpoints when appropriate.

Do not create affiliate accounts until a specific transition survives this pressure test strongly enough to justify accepting program terms.
