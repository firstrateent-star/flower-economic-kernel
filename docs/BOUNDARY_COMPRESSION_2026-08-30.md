# Boundary Compression — 2026-08-30

## Trigger

Changed Method Navigator reached a human-only Marketplace membrane after technical truth, problem evidence and market-prep evidence had already been established. Continuing speculative feature work was unjustified, but handing the Center-holder a broad instruction such as "publish the plugin" would still externalize avoidable machine work onto the human.

The remaining boundary was therefore compressed.

## Law

> **Before requesting human actuation, consume every reversible, non-sovereign uncertainty that can be resolved safely by the machine. Leave only identity, legal status, irreversible exposure, relationship authority, payment authority, or other genuinely human decisions.**

The goal is not zero human participation. The goal is maximal autonomous preparation per unit of human sovereignty consumed.

## Boundary decomposition

A broad actuation such as:

`publish plugin`

usually hides multiple sub-actions:

- finish implementation;
- run tests;
- build a distribution artifact;
- check compatibility;
- prepare truthful listing copy;
- prepare required assets;
- choose price/visibility experiment defaults;
- choose vendor identity;
- choose legal/business declarations;
- accept platform agreements;
- authorize external distribution.

Flower should separate these into two sets.

### Machine-resolvable set

Examples:

- technical verification;
- deterministic packaging checks;
- current platform-rule research;
- nonbinding listing copy;
- reversible assets;
- experiment design;
- free/hidden/no-feature-expansion defaults when those are clearly the lowest-risk evidence probe;
- collision/search checks;
- evidence-state reconciliation.

### Human-sovereign set

Examples:

- real public identity/vendor name;
- trader/non-trader or comparable legal status;
- acceptance of agreements;
- EULA/license selection when it creates legal obligations;
- banking/payment identity;
- authorization of public or external distribution;
- direct human relationship/contact commitments;
- irreversible publication choices.

The machine must not collapse the second set into the first merely to increase autonomy.

## Compression objective

A useful ordering concept is:

`BoundaryBurden = HumanMinutes × SovereigntyCost × Irreversibility × SetupEntropy`

and:

`CompressionGain = AvoidedHumanBurden / MachineSafeWork`

The terms are qualitative ordering aids, not literal measurements.

The desired transition is:

`BROAD HUMAN TASK -> DECOMPOSE -> MACHINE CLEARS REVERSIBLE WORK -> MINIMAL SOVEREIGN DECISION -> EXTERNAL RETURN`

## Changed Method Navigator example

Before compression, the human boundary looked like:

`get this onto JetBrains Marketplace`

After compression, the machine has already completed:

- real IntelliJ PSI functional verification;
- real IntelliJ SDK build;
- Plugin Verifier current-target verification;
- Marketplace description;
- change notes;
- 40×40 SVG icon;
- distribution ZIP inspection;
- hidden/free/no-public-unhide probe defaults;
- no-feature-expansion stop rule;
- supporting name/plugin-ID collision search.

The remaining human membrane is therefore limited to:

1. real vendor public identity/contact;
2. legal/business declaration such as trader/non-trader status;
3. EULA/license choice;
4. explicit authorization of hidden external distribution.

After those choices, the machine only needs bounded metadata finalization and the same already-green CI before upload.

## New invariant

> **Do not hand the Center-holder a task the machine could have safely reduced first.**

But also:

> **Do not erase sovereignty merely because the remaining choice is inconvenient to automation.**

Both sides are necessary.

## Relationship to Human Actuation Portfolio

Human Actuation Portfolio decides **which** human boundary deserves scarce attention.

Boundary Compression decides **how much** of that boundary should actually reach the human.

Together:

`MATURE ORGANISMS -> ACTUATION RANKING -> BOUNDARY COMPRESSION -> MINIMAL HUMAN CHOICE -> RETURN`

## Stopping rule

When a branch has:

- saturated safe machine-side evidence;
- a verified artifact;
- a ranked human membrane;
- and a compressed decision packet containing only sovereignty choices,

then additional adjacent research, platform comparison, cosmetic polish, or feature work is negative-value unless new evidence changes the ranking.

At that point Flower should park autonomous work on that branch and allow other organisms to continue independently.
