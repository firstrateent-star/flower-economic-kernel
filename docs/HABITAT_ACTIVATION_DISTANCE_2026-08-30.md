# Habitat Activation Distance — 2026-08-30

## Trigger

After pruning several standalone validator ideas, Flower widened once more to ask whether a different platform with built-in distribution and billing could beat the current highest-ranked human actuation: market exposure for Changed Method Navigator.

The comparison surfaced an important distinction:

> **A good habitat with no surviving organism should not outrank a good-enough habitat containing an already verified organism merely because the new habitat has attractive economics.**

## Current observed habitats

### JetBrains Marketplace

Current properties observed 2026-08-30:

- no additional development/listing fee;
- JetBrains currently retains 15% of plugin sales;
- hidden status can be selected on the initial upload;
- a hidden plugin still undergoes approval but is omitted from Marketplace search, IDE search and search-engine discovery;
- a hidden plugin remains directly installable by link and can later be made public;
- un-hiding the plugin is irreversible;
- initial upload requires acceptance of the Marketplace Developer Agreement, a Vendor profile, and a Developer EULA;
- paid release adds trader/banking/sales setup.

Existing Flower organism: Changed Method Navigator.

Current state:
- real IntelliJ PSI functional test: passed;
- real SDK build: passed;
- current-target Plugin Verifier: passed;
- independent problem evidence: present;
- adjacent paid-market evidence: present;
- remaining uncertainty: independent user adoption.

Activation distance: low relative to the other newly scanned habitats because the organism already exists.

### Atlassian Marketplace / Forge

Current properties observed 2026-08-30:

- Paid via Atlassian provides native customer evaluation/purchase, licensing and sales reporting;
- qualifying Forge apps receive 100% of gross Forge revenue up to $1M lifetime Forge revenue as of 2026;
- tax/legal/payout setup and end-user terms are still required;
- recurring billing is native to the parent workflow.

Existing Flower organism: none.

Activation distance: high because product/problem selection, implementation, technical validation and market validation all remain before the legal/payout membrane.

### Shopify App Store

Current properties observed 2026-08-30:

- built-in app billing and recurring app economics are mature;
- developers keep 100% of the first $1M gross app revenue under the current program, subject to processing fees;
- App Store registration requires a one-time $19 fee.

Existing Flower organism: none.

Activation distance: high and violates strict Seed-0 for a fresh speculative branch before an organism has earned the fee.

### GitHub Marketplace paid apps

Current properties observed 2026-08-30:

- native GitHub billing supports paid monthly/yearly app plans;
- GitHub retains 5% of post-2021 transaction income under current documentation;
- paid apps require verified publisher/financial onboarding;
- GitHub Apps should have at least 100 installations before Marketplace listing (OAuth apps: 200 users);
- Marketplace purchase-event handling and customer plan-state UX are required.

Existing Flower organism: none that clears the install threshold.

Activation distance: very high for first-dollar germination despite attractive billing economics.

### Canva Apps

Current properties observed 2026-08-30:

- Canva's Premium Apps Program can provide recurring payouts based on use inside paid plans;
- apps can also use external payment links;
- Canva is explicitly shifting its developer monetization emphasis toward deeper integrations and niche workflows that simple AI replication cannot easily replace.

Existing Flower organism: none.

Activation distance: high because program application/selection and new product work precede economic return.

## New law: Activation Distance

Habitat attractiveness must be discounted by the distance from the Garden's **current state**, not measured from a blank slate.

A useful ordering aid:

`AdjustedHabitatValue = NativeDemand × NativeBilling × Repeatability × Distribution / (1 + BuildDistance + ValidationDistance + HumanActivation + Capital + Irreversibility)`

The denominator must include uncertainty already paid down by existing organisms.

This prevents a recurring error:

`discover attractive platform -> abandon nearly mature organism -> restart at idea stage`.

## Existing-organism advantage

When comparing a new habitat `H_new` to an existing organism `O_existing`, explicitly credit sunk **knowledge**, not sunk cost.

Sunk monetary/time cost should not preserve a bad branch. But verified capability and eliminated uncertainty are real assets.

Therefore:

`ExistingAdvantage = VerifiedCapability + EliminatedUncertainty + ReadyArtifact + Evidence + ReusableDistributionPrep`

If current counter-evidence has not invalidated those assets, they reduce future activation distance.

## Current conclusion

None of the newly scanned parent-flow marketplaces currently beats Changed Method Navigator on **decision-changing evidence returned per next human action**.

This is not a claim that JetBrains is the best software market generally.

It is a state-relative claim:

`Given this Garden now, the shortest evidence-bearing path is Changed Method Navigator -> hidden/low-discovery external exposure -> independent user return.`

Atlassian, Shopify, GitHub Marketplace and Canva remain habitat knowledge, not active builds.

## Stopping rule

When a bounded habitat scan finds no alternative with lower activation distance and higher expected regenerative return than the highest-ranked mature organism, stop scanning platforms.

Do not use platform discovery as a way to avoid the human membrane.

Compact form:

`GOOD HABITAT + NO ORGANISM < MATURE ORGANISM + ONE EVIDENCE MEMBRANE`

when the mature organism's surviving evidence remains stronger and the membrane is reversible enough to test safely.
