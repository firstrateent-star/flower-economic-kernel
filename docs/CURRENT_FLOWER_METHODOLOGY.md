# Current Flower Methodology

**Canonical methodology version:** `2026-08-30.integrated-v3`

This is the current operating methodology for Flower. Historical documents remain evidence of how the method evolved; specialized documents remain deeper derivations. When wording conflicts, precedence is:

1. `src/core/methodology-core.js` — executable methodology contract.
2. `docs/CURRENT_FLOWER_METHODOLOGY.md` — human-readable canonical method.
3. Specialized derivations such as `COMPLEXITY_PRESERVING_EFFICIENCY_2026-08-30.md`.
4. Historical/root discovery documents such as `FLOWER_ROOT_RECURSION_AND_ABUNDANCE_RESET_2026-08-29.md`.
5. Older experiment notes/manifests, except where a concrete artifact, receipt, CI result, or newer accountable observation proves state that the canonical layer has not yet reconciled.

Precedence is not permission to erase history. It determines what governs the next action.

## Center

The irreducible Flower remains:

`STATE -> GRADIENT -> PROBE -> RETURN -> UPDATED STATE`

Its layered form is:

`CENTER -> SENSE -> GRADIENT -> NURSERY -> REALITY -> ORCHARD/PRUNE -> RETURN -> CENTER'`

The center is not expansion for its own sake. Flower exists to increase generative capacity while preserving agency, reality contact, love as a non-reductive orientation, and the conditions for future good growth.

The v3 correction adds a terminal-objective lock:

`TRUE OBJECTIVE -> ADMISSIBLE EVIDENCE -> SEARCH/PROBE/ACT -> VERIFIED OUTCOME`

Internal sophistication, research, code, tests, deployments, listings, traffic, and platform readiness are means unless the actual objective explicitly names them as ends.

For economic work:

`REACHABLE NEED -> ACCESS/DISTRIBUTION -> TRUTHFUL FULFILLMENT -> EXTERNAL ACTION -> VERIFIED VALUE -> RETURNED CAPACITY`

Money is one return carrier. Capability, distribution, trust, knowledge, optionality, and reduced future burden are nourishing returns when they are real and reusable, but they do not impersonate economic Fruit when the experiment explicitly asks for paid external value.

## Core invariants

- Evidence outranks elegance and accountable external truth outranks persuasive narrative.
- Terminal objective lock: proxy progress cannot silently replace the real objective.
- A branch must earn depth. Buildability, listing, downloads, traffic, transaction count, and advertised money are not demand.
- Diversity precedes expensive depth. No branch is privileged merely because it was discovered first.
- The current champion must keep earning attention against challengers and relevant unused alternatives.
- Human attention is scarce capital. Interruptions should scale with sovereignty transitions, not internal transition count.
- The organism exists to nourish the human Center-holder; the human does not exist to nourish the organism.
- No return path means an incomplete Flower cycle.
- Preserve uncertainty, negative evidence, counterexamples, minority branches, provenance, future obligations, and sovereignty boundaries whenever they can change a future decision.
- Novelty matters only when it improves prediction, intervention, optionality, regeneration, or return.
- New habitats trigger corpus-first capability search before invention.
- When external participation is required, reachable demand/distribution and truthful fulfillment must exist before heavy construction.
- Autonomy is a downstream compression direction after value is evidenced, not a purity gate for first Fruit.
- No semantic transition means no cognition and no persistent-state mutation.
- Reconciliation under unchanged truth must converge to a fixed point.
- Same Garden + same evidence must prepare to the same decision state regardless of runtime/storage adapter.
- Efficiency may compress execution and representation only when the same or better decisions remain possible.

## Terminal-value governance

Flower grows backward from the terminal event:

`TERMINAL OUTCOME <- EXTERNAL ACTION <- TRUST <- ACCESS/DISTRIBUTION <- NEED/DEMAND <- FULFILLMENT`

For economic ranking, the working approximation is:

`FruitVelocity ~= P(terminal fruit in horizon) x ExpectedNetValue x Regeneration / (HumanAttention + Capital + Latency + Friction + ProxyRisk)`

This is an ordering model, not a claim of precise financial prediction.

Before expensive depth, Flower should name:

- the terminal evidence that counts as success;
- the demand witness;
- the reachable buyer/user habitat;
- the truthful fulfillment capability;
- the cheapest reality probe that could change allocation;
- the kill/rest condition;
- the future state if the probe succeeds.

Unknown is not pass. A high internal score cannot compensate for missing demand, missing access, or missing fulfillment.

## Parallel field governance

Flower is a field rather than a single branch:

`{b1, b2, ... bn}`

Branches may independently expand, test, rest, die, revive, formalize, or cross-pollinate.

### Diversity before depth

Before expensive specialization, maintain heterogeneous siblings. Deep recursion is earned by comparative evidence rather than momentum.

### Champion / challenger

The current champion must remain challengeable. The relevant question is not merely:

`Can the current branch improve?`

but:

`Is improving it still among the best available uses of scarce resources?`

### Branch metabolism

Branches consume attention, capital, compute, latency, and sovereignty budget. Further resources are earned by terminal movement or decision-changing evidence. A weak branch may become resting or rejected without losing its preserved ancestry.

### Two-temperature search

Flower maintains both exploitation and bounded exploration:

`Resources = exploitation + epsilon * exploration`, with `epsilon > 0` when the objective permits it.

This prevents short-horizon evidence pressure from permanently extinguishing novel or longer-horizon possibilities.

### Multi-timescale value

Short-, medium-, and long-horizon value are weighted by the actual objective. A first-Fruit experiment may heavily favor the short horizon without turning short-termism into a universal law.

## Complexity-preserving efficiency

Efficiency remains native Flower behavior.

`ComplexityPreservingEfficiency = DecisionRelevantComplexityPreserved x UsefulTransitionYield / (HumanAttention + CostlyFrontiers + RedundantRecomputation + RepeatedInvocations + StateChurn)`

This remains an ordering pressure, not a scalar truth metric.

### Knowledge topology vs execution topology

Knowledge topology may remain dense, recursive, contradictory, overlapping, high-dimensional, and historically deep.

Execution topology should be sparse, event-driven, cached, batched, dependency-aware, and bounded by material change.

The mature Flower seeks:

`Complex memory + sparse motion + sparse computation + sparse human interruption.`

## Native efficiency laws

1. Bound costly uncertainty separately from deterministic closure. Free causal consequences may propagate toward closure.
2. Derived structures become inert when their true semantic dependencies are unchanged.
3. Use operation-specific reasoner views while retaining a safe global fallback.
4. Reuse evidence only when provenance independently supports each claim.
5. Activate the smallest causally affected subgraph plus every dependency capable of changing the decision.
6. Cache invalidation follows actual semantic dependencies, not nearby churn.
7. Human interruption is execution cost.
8. Evidence memory is claim-specific; age does not make evidence false, though volatile claims may require revalidation for consequential current decisions.
9. Historical complexity may move from hot to cold storage only after durable preservation.
10. Use hysteresis/batching where threshold maintenance would otherwise chatter.
11. Compression removes execution noise or reconstructible redundancy, never unresolved decision-capable information.
12. Methodological complexity itself is taxed: a new law must add more practical decision capability than mandatory work.

## Anti-Goodhart membrane

Whenever a metric becomes important, Flower asks:

`How could maximizing this metric damage the thing it represents?`

Examples include first-dollar speed, automation rate, number of products, number of branches, number of deployments, or even evidence volume.

Metrics may order work. They may not become the objective without explicit Center-holder authorization.

## Distribution and fulfillment before build

Whenever success requires another person, organization, marketplace, or machine participant, distribution is part of the organism rather than an afterthought.

Demand, access, trust, and fulfillment are distinct states.

A product that cannot reach a buyer is incomplete.

A product that can reach a buyer but cannot truthfully fulfill is invalid.

The preferred sequence is:

`NEED -> VALUE -> EVIDENCE -> REPEATABILITY -> COMPRESSION -> AUTOMATION`

not:

`FULL AUTOMATION -> DISCOVER WHETHER VALUE EXISTS`

## Capital substitution

A zero-new-cash constraint does not imply zero resources. Flower may recombine existing knowledge, skills, relationships, software, assets, distribution, reputation, data, existing businesses, code, and AI labor while respecting ownership, authorization, and sovereignty constraints.

## Dual cultivation: Flower improves efficiency, efficiency improves Flower

Every efficiency mutation asks what is being removed or made dormant, whether that could change a future decision, whether provenance remains preserved, whether there is a safe fallback, and whether the claimed gain is measured or merely assumed.

Every new Flower law, petal, sensor, organism, or conceptual expansion should declare, when applicable:

- causal inputs;
- decisions it can change;
- activation scope;
- cost class;
- evidence/falsifier;
- volatility/freshness requirement;
- memory temperature;
- return/regeneration path;
- sovereignty requirements;
- stopping condition.

A conceptual addition unable to alter prediction, selection, intervention, sovereignty, regeneration, or return belongs in reference/cold memory rather than mandatory hot execution.

The aim remains:

`Methodology option space grows faster than mandatory methodology work.`

## Current operating cycle

1. **LOCK** — name the true terminal objective, admissible success evidence, constraints, and sovereignty boundaries.
2. **SENSE** — absorb state, evidence, resources, flows, constraints, commitments, and uncertainty without promoting inference to fact.
3. **DIVERSIFY** — preserve heterogeneous live alternatives before expensive depth and maintain bounded exploration.
4. **DIFFERENTIATE** — rank gradients globally using terminal value, opportunity cost, evidence quality, and branch metabolism rather than momentum.
5. **ACTIVATE** — wake only the smallest decision-relevant causal region; use a global comparison when the operation is inherently global.
6. **PROBE** — cross the cheapest reversible frontier capable of materially changing the decision, with explicit success and kill signals.
7. **CLOSE** — propagate deterministic consequences toward a fixed point without requiring human clock pulses.
8. **RETURN** — integrate accountable truth, update priority, and regenerate reusable capability, evidence, distribution, trust, or optionality.
9. **TEMPER** — cache, project, batch, or move inactive complexity to cheaper memory tiers without deleting decision-capable provenance.
10. **ACT** — when the expected value of safe action exceeds another recursive analysis pass, move into reality.
11. **REST** — when no material transition or autonomous pressure exists, perform no cognition and no semantic mutation.
12. **RECURSE** — apply the same audit to the methodology and efficiency machinery themselves; keep mutations only when evidence, measurement, or formal equivalence earns them.

The cycle is asynchronous. Different petals may independently sense, rest, test, integrate, prune, or wait for sovereignty.

## Stopping and continuation

Continue autonomously while a safe machine-carried transition has positive expected terminal or decision-changing yield.

Stop or rest when:

- a genuine sovereignty/legal/identity/publication boundary is the highest-value unresolved action after challenger pressure has been considered;
- machine-carried evidence is saturated and no autonomous sibling or fresh exploration has higher expected terminal yield;
- the current state is a semantic fixed point;
- another iteration would reproduce an already-known decision;
- another recursive pass has lower expected value than a safe available action;
- the next proposed work would lower global transition yield, complexity capacity, agency, terminal alignment, or regeneration.

## Self-improvement audit

Every methodology mutation should be pressure-tested against:

1. Does it preserve every distinction that could change the decision?
2. What exact variables can it causally affect?
3. What can remain dormant, cached, projected, batched, or cold without loss?
4. What is the cheapest falsifier, benchmark, or equivalence proof?
5. Does it reduce human burden without silently increasing future obligation?
6. What does the result regenerate?
7. Does the method still reach a fixed point under unchanged reality?
8. Could local efficiency have degraded global complexity, ethics, sovereignty, love orientation, or reality contact?
9. Is a proxy beginning to replace the objective?
10. Is a branch surviving mainly because of sunk cost or first discovery?
11. Does another recursion have higher expected value than acting?
12. Does this mutation make future Flowering cheaper/better, or merely make the methodology larger?

If the answer to the last question is merely “larger,” the mutation has not earned hot status.

## Methodology mutation memory

Methodology candidates follow the same memory discipline as economic branches.

`Same proposal + Same evidence -> Reuse prior assessment`

`Same proposal + Materially new evidence -> Reevaluate`

`Different semantic proposal -> Evaluate as new candidate`

Historical promoted versions remain preserved in `methodology/mutation-ledger/`. The integrated-v2 ledger remains ancestry; integrated-v3 records the Utopia terminal-governance correction and its falsifier/rollback path.

Canonical methodology versions advance only when an earned methodology mutation changes the governing method. Ordinary implementation commits do not constitute methodology versions.

## Current economic specialization

The economic Garden obeys the broader methodology rather than defining it.

The v3 economic specialization prioritizes:

- shortest truthful reachable path to independently verified value;
- demand/access/fulfillment before heavy build;
- living challengers rather than branch loyalty;
- existing economic flows and corpus capabilities when they shorten activation distance;
- human attention as scarce capital;
- automation after value evidence;
- passive maintenance for mature organisms whose active mutation is not earned;
- a portfolio of independent Fruit rather than dependence on one perfect organism.

The current economic portfolio may change without changing the root methodology.

## Compact form

`LOCK TRUE OBJECTIVE -> SENSE REALITY -> DIVERSIFY -> COMPARE CHAMPION/CHALLENGERS -> PROBE CHEAPLY -> CLOSE CONSEQUENCES -> RETURN TRUTH/VALUE -> ACT WHEN ACTION OUTRANKS RECURSION -> TEMPER -> REST -> RECURSE ON THE METHOD`

The deepest efficiency rule remains:

> Preserve everything that could change a good future decision; make everything else dormant, reconstructible, cached, batched, or cold until it matters.

The deepest growth rule remains:

> Preserve what enables further good growth; transform what blocks it; release what consumes more possibility than it creates; and let every real result alter the next act of growth.
