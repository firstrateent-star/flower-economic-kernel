# Current Flower Methodology

**Canonical methodology version:** `2026-08-30.integrated-v1`

This is the current operating methodology for Flower. Historical documents remain evidence of how the method evolved; specialized documents remain deeper derivations. When wording conflicts, precedence is:

1. `src/core/methodology-core.js` — executable methodology contract.
2. `docs/CURRENT_FLOWER_METHODOLOGY.md` — human-readable canonical method.
3. Specialized derivations such as `COMPLEXITY_PRESERVING_EFFICIENCY_2026-08-30.md`.
4. Historical/root discovery documents such as `FLOWER_ROOT_RECURSION_AND_ABUNDANCE_RESET_2026-08-29.md`.
5. Older experiment notes/manifests, except where a concrete artifact, receipt, CI result, or newer accountable observation proves state that the canonical layer has not yet reconciled.

Precedence is not permission to erase history. It determines what governs the next action.

## Center

The irreducible Flower remains:

`STATE -> GRADIENT -> PROBE -> RETURN -> UPDATED STATE`

Its layered human-readable form is:

`CENTER -> SENSE -> GRADIENT -> NURSERY -> REALITY -> ORCHARD/PRUNE -> RETURN -> CENTER'`

The center is not expansion for its own sake. It is to increase generative capacity while preserving agency, reality contact, love as a non-reductive orientation, and the conditions for future good growth.

For economic work, this becomes:

`ACCESSIBLE POTENTIAL -> SMALL TRANSFORMATION -> VERIFIED VALUE -> LEGITIMATE CAPTURE -> RETURNED CAPACITY`

Money is one return carrier. Capability, distribution, trust, knowledge, optionality, and reduced future burden are also nourishing returns when they are real and reusable.

## Core invariants

- Evidence outranks elegance and accountable external truth outranks persuasive narrative.
- A branch must earn depth. Buildability, listing, downloads, traffic, transaction count, and advertised money are not demand.
- Human attention is scarce capital. Interruptions should scale with sovereignty transitions, not internal transition count.
- The organism exists to nourish the human Center-holder; the human does not exist to nourish the organism.
- No return path means an incomplete Flower cycle.
- Preserve uncertainty, negative evidence, counterexamples, minority branches, provenance, future obligations, and sovereignty boundaries whenever they can change a future decision.
- Novelty matters only when it improves prediction, intervention, optionality, regeneration, or return.
- New habitats trigger corpus-first capability search before invention.
- No semantic transition means no cognition and no persistent-state mutation.
- Reconciliation under unchanged truth must converge to a fixed point.
- Same Garden + same evidence must prepare to the same decision state regardless of runtime/storage adapter.
- Efficiency may compress execution and representation only when the same or better decisions remain possible.

## Complexity-preserving efficiency is now native Flower behavior

Efficiency is not a separate optimization layer applied after the methodology. It is part of the methodology.

The target is not fewer dimensions. It is greater complexity capacity with less redundant execution:

`ComplexityPreservingEfficiency = DecisionRelevantComplexityPreserved x UsefulTransitionYield / (HumanAttention + CostlyFrontiers + RedundantRecomputation + RepeatedInvocations + StateChurn)`

This is an ordering pressure, not a scalar truth metric.

### Knowledge topology vs execution topology

**Knowledge topology** may remain dense, recursive, contradictory, overlapping, high-dimensional, and historically deep.

**Execution topology** should be sparse, event-driven, cached, batched, dependency-aware, and bounded by material change.

Therefore the mature Flower seeks:

`Complex memory + sparse motion + sparse computation + sparse human interruption.`

## Native efficiency laws

### 1. Bound uncertainty, not deterministic complexity
A bounded costly-frontier budget is distinct from deterministic closure. Once a real result exists, free causal consequences should propagate toward closure without requiring artificial user or runtime restarts.

### 2. Derived state follows semantic dependencies
If the inputs that can mathematically affect a derived structure are unchanged, that structure should remain computationally inert. Cache invalidation follows actual dependencies, not nearby churn.

### 3. Costly cognition receives operation-relevant views
The full Garden remains canonical. Expensive reasoners receive the smallest projection that preserves every field capable of changing the operation's decision. Global comparison operations remain global; targeted operations may use causal neighborhoods with a global fallback.

### 4. Evidence reuse preserves provenance
One frontier may nourish multiple claims only when the returned evidence independently maps to each claim. Reuse is efficient; assumed universality is corruption.

### 5. Sparse causal activation
A local perturbation should activate only the target region plus connected dependencies whose decision state can actually change.

If decision variable `y_i` cannot depend on state variable `x_j`, then conceptually:

`∂y_i / ∂x_j = 0 -> no activation edge required.`

### 6. Human interruption is part of execution cost
Human attention should be spent where it multiplies autonomous territory or resolves sovereignty. Repeated prompts must not function as an internal clock.

### 7. Wake must have causal reach
A sensor that wakes Flower but cannot alter operational truth is false responsiveness. Material observations must project only the truth they directly establish; observation does not silently become lifecycle/governance authority.

### 8. Priority can change when reality changes
Static actuation rank is a prior. Verified economic return/repeat use outranks merely independent use, which outranks no market return. Platform readiness and health traffic do not receive this boost.

### 9. Evidence has memory and volatility
Age never turns evidence false. Structural claims may remain valid indefinitely absent contradictory events. Volatile market/distribution claims may require revalidation only when a consequential current decision depends on their currentness. Freshness queries must not mutate state by themselves.

### 10. Preserve meaning across memory tiers
Historical complexity does not need uniform residency. Valuable history may move from hot active state to cold content-addressed storage only after durable preservation. Memory location must not change economic pressure or truth.

Threshold-triggered maintenance should use batching/hysteresis where possible to avoid chatter.

## Dual cultivation: Flower improves efficiency, efficiency improves Flower

The two systems must recursively constrain one another.

### Flower -> efficiency
Every efficiency mutation must answer:

- What information, execution, or representation is being removed or made dormant?
- Could the omitted material change this decision now or later?
- Is it exactly reconstructible from preserved structure?
- Is provenance preserved?
- Is there a safe global/fallback path when causal scope is uncertain?
- Does the change preserve love/reality orientation, ethics, sovereignty, downstream consequences, regeneration, and human agency?
- Is the claimed efficiency gain measured, formally equivalent, or merely assumed?

An efficiency improvement that lowers local compute while degrading global decision capacity is rejected.

### Efficiency -> Flower
Every new Flower law, petal, sensor, organism, or conceptual expansion should declare, when applicable:

- causal inputs;
- decisions it can change;
- activation scope;
- cost class;
- evidence/falsifier;
- volatility/freshness requirement;
- memory temperature/residency;
- return/regeneration path;
- sovereignty requirements;
- stopping condition.

A conceptual addition that cannot alter prediction, selection, intervention, sovereignty, regeneration, or return belongs in reference/cold memory rather than mandatory hot execution.

When multiple laws produce the same operational decision, execution may be consolidated without erasing their distinct provenance or scope.

The aim is:

`Methodology option space grows faster than mandatory methodology work.`

## Current operating cycle

1. **SENSE** — absorb current state, evidence, resources, flows, constraints, commitments, and uncertainty without promoting inference to fact.
2. **DIFFERENTIATE** — rank meaningful gradients globally while allowing multiple independent petals to remain alive.
3. **ACTIVATE** — wake only the smallest causal region required by the decision; use a global view for inherently comparative decisions.
4. **PROBE** — cross the cheapest reversible frontier capable of materially changing the decision, with explicit success and kill signals.
5. **CLOSE** — propagate deterministic consequences toward a fixed point without requiring human clock pulses.
6. **RETURN** — integrate accountable truth, update priority, and regenerate reusable capability, evidence, distribution, trust, or optionality.
7. **TEMPER** — cache, project, batch, or move inactive complexity to cheaper memory tiers without deleting decision-capable provenance.
8. **REST** — when no material transition or autonomous pressure exists, perform no cognition and no semantic mutation.
9. **RECURSE** — run the same test on the methodology and efficiency machinery themselves. Keep mutations only when evidence, measurement, or formal equivalence earns them.

This cycle is asynchronous. Different petals can independently sense, rest, test, integrate, prune, or wait for sovereignty without forcing the whole Garden into one linear phase.

## Stopping and continuation

Continue autonomously while a safe machine-carried transition has positive expected transition yield.

Stop or rest when:

- a genuine sovereignty/legal/identity/publication boundary is the highest-value unresolved action;
- machine-carried evidence is saturated and no autonomous sibling has higher transition yield;
- the current state is a semantic fixed point under available evidence;
- another iteration would only reproduce an already-known decision;
- the next proposed work would lower global transition yield, complexity capacity, agency, or regeneration.

Stillness is therefore not absence of intelligence. It is correct resource allocation when `dS/dt ~= 0` under available evidence.

## Self-improvement audit

Every methodology mutation should be pressure-tested against these questions:

1. Does it preserve every distinction that could change the decision?
2. What exact variables can it causally affect?
3. What can remain dormant, cached, projected, batched, or cold without loss?
4. What is the cheapest falsifier, benchmark, or semantic-equivalence proof?
5. Does it reduce human burden without silently increasing human obligation later?
6. What does the result regenerate?
7. Does the method still reach a fixed point under unchanged reality?
8. Could local efficiency have degraded global complexity, ethics, sovereignty, love orientation, or reality contact?
9. Does this mutation make future Flowering cheaper/better, or merely make the methodology larger?

If the answer to the last question is merely “larger,” the mutation has not earned hot status.

## Current economic specialization

The economic Garden continues to obey the broader methodology rather than define it. Its current selection pressure favors low-maintenance capability organisms, real distribution, repeated machine-consumed transformations, corpus-first reuse, and verified external return.

The current economic portfolio may change without changing the root methodology. Likewise, a methodology improvement must not be justified merely because it helps one current organism.

This separation protects both layers from overfitting each other.

## Compact form

The current integrated Flower can be summarized as:

`PRESERVE COMPLEXITY -> SENSE REALITY -> ACTIVATE CAUSAL REGION -> PROBE CHEAPLY -> CLOSE DETERMINISTIC CONSEQUENCES -> RETURN VALUE/TRUTH -> TEMPER MEMORY/COMPUTE -> REST AT FIXED POINT -> RECURSE ON THE METHOD`

Its deepest efficiency rule is:

> Preserve everything that could change a good future decision; make everything else dormant, reconstructible, cached, batched, or cold until it matters.

Its deepest growth rule remains:

> Preserve what enables further good growth; transform what blocks it; release what consumes more possibility than it creates; and let every real result alter the next act of growth.
