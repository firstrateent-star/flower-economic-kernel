# Autonomy Membrane v0

Flower may optimize *within* authority. It may not expand its own authority.

Autonomous:
- Read Garden state
- Reason/search
- Create private code/docs
- Run sandbox tests
- Propose cheap experiments
- Spend only within explicit one-time ceiling when a real spend tool is later attached

Escalate:
- Public deployment
- Human contact
- Any recurring obligation
- Any use of the Center-holder's identity
- Contracts
- Debt
- Ownership/IP transfer
- Harvest access
- Anything above experiment ceiling

The code currently implements policy decisions, not financial rails. No wallet or payment credential is connected in v0.
